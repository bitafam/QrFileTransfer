# راهنمای ساخت فایل APK در گیتهاب (GitHub Actions)

این پروژه مجهز به یک ورکفلو خودکار **GitHub Actions** به آدرس `.github/workflows/build-apk.yml` است که به شما امکان می‌دهد بدون نیاز به نصب اندروید استودیو روی سیستم خود، فایل خروجی **APK** اندروید را دریافت کنید.

---

## 🚀 روش‌های اجرا و دریافت فایل APK

### روش اول: اجرای دستی (Manual Trigger)
۱. پروژه‌تان را به مخزن (Repository) خود در **GitHub** پوش کنید.
۲. وارد تب **Actions** در بالای صفحه گیتهاب شوید.
۳. از منوی سمت چپ، روی **Build Android APK** کلیک کنید.
۴. روی دکمه **Run workflow** کلیک کرده و گزینه **Run workflow** را تایید کنید.
۵. پس از اتمام ساخت (حدود ۳ الی ۵ دقیقه)، روی بیلد موفق کلیک کنید و در بخش **Artifacts** فایل `QR-File-Transfer-APK` را دانلود کنید.

---

### روش دوم: ساخت خودکار با Commit
با هر بار `git push` روی شاخه `main` یا `master`، ورکفلو به صورت خودکار اجرا شده و فایل APK تازه ساخت را آماده می‌کند.

---

### روش سوم: ایجاد نسخه Release (با Tag)
اگر یک تگ نسحه مثل `v1.0.0` روی گیتهاب بفرستید:
```bash
git tag v1.0.0
git push origin v1.0.0
```
ورکفلو به صورت خودکار یک **Release** رسمی در گیتهاب ایجاد کرده و فایل `QR_File_Transfer.apk` را ضمیمه آن می‌کند.

---

## 🛠 ویژگی‌های تنظیم شده در ورکفلو:
- تنظیم خودکار Java JDK 17 و SDK اندروید.
- ساخت خودکار پروژه وب توسط Vite.
- یکپارچه‌سازی و همگام‌سازی Capacitor با محیط اندروید.
- افزودن خودکار مجوزهای لازم مانند **دسترسی به دوربین (`android.permission.CAMERA`)** جهت اسکن بارکد.
- تولید و ارائه فایل نهایی `QR_File_Transfer.apk`.
